Forma て

Grupy czasowników

GrupaRozpoznanieForma て
czasownik る-iru / -eruる → て　食べる → 食べて　見る → 見て
czasownik ureszta; -aru / -uru / -oru zawszewedług końcówki (niżej)
nieregularneする・来るして・来て（きて）

Czasowniki u, które udają る: 帰る・入る・走る・知る・切る → 帰って・入って・走って・知って・切って

Trzy różne „wyjątki”, nie myl ich:

  • 帰る・入る・走る・知る・切る to zwykłe czasowniki u, tylko wyglądają jak る. W drugą stronę to nie działa: 起きる・見る・寝る・着る・教える to czasowniki る → 起きて・見て・寝て・着て・教えて (✗ 起きって).
  • 行く to czasownik u z jedną nieregularną formą: 行って, a nie ✗ 行いて.
  • Nieregularne są tylko dwa: する i 来る.

Tam, gdzie dwa czasowniki dają tę samą formę, rozstrzyga kontekst.

～てください: grzeczna prośba

Chcesz…WzórPrzykład
rzeczrzeczownik + を + ください水を　ください。

Zestaw ratunkowy: ゆっくり話してください・もう一度言ってください・ちょっと待ってください.

✗ 待ちください. Usłyszysz za to 少々お待ちください (bardzo grzeczny język obsługi: お + rdzeń ます + ください). Rozumiesz, ale sam mówisz 待ってください.

～ています: teraz, stan, nawyk

ZnaczeniePrzykładSygnał
czynność trwa teraz今、本を　読んでいます。今・もしもし
stan, który trwa東京に　住んでいます。田中さんを　知っています。傘を　持っています。結婚しています。住む・知る・持つ・結婚する
nawyk, praca銀行で　働いています。毎日　日本語を　勉強しています。毎日・会社で

Pytanie: ～ていますか. Przeczenie: ～ていません. Wyjątek: 知っていますか → はい、知っています / いいえ、知りません (✗ 知っていません).

✗ 読みています: います łączy się z formą て, tak jak ください. Potocznie い wypada: 読んでる・知ってる・何してるの？

～てもいいですか／～てはいけません: wolno i nie wolno

WzórPrzykład
czy mogę?forma て + もいいですか写真を　撮ってもいいですか。　ここに　座ってもいいですか。
wolnoforma て + もいいですここで　食べてもいいです。
nie wolnoforma て + はいけませんここで　写真を　撮ってはいけません。

Odpowiedzi: tak = はい、どうぞ・ええ、いいですよ; nie = すみません、ちょっと…・いいえ、～てはいけません・だめです.

Jedna sylaba decyduje: ても → いい, ては → いけません. は czytasz „wa”. Po んで tak samo: 飲んでもいいですか・読んではいけません. ✗ 書きてはいけません (rdzeń ます).

Potocznie: ては → ちゃ, では → じゃ: 見ちゃだめ・飲んじゃいけない. „Nie musisz” to ～なくてもいいです (forma ない, tydzień 4).

Łączenie zdań przez て: i potem, i do tego

Co łączyszWzórPrzykład
czasowniki (kolejność)forma て、forma て、ostatni czasownik朝　起きて、シャワーを　浴びて、朝ご飯を　食べます。
czasowniki: dopiero poforma てから、…切符を　買ってから、電車に　乗ります。
przymiotnik いい → くて安くて、おいしいです。　いい → よくて
przymiotnik な, rzeczownik+ で静かで、きれいです。　学生で、二十歳です。

Czas i grzeczność tylko na końcu: 買って、乗って、帰りました. Forma て sama w sobie nie ma czasu. Po て naturalna jest przecinek-pauza (、).

Te same znaki, inne czasowniki: 買う → 買って (kupić), 会う → 会って (spotkać), 言う → 言って (powiedzieć). W czasownikach u końcówka wymienia się na って: ✗ 吸うって, ✗ 買うって.

Ten sam kierunek: くて／で łączy cechy, które do siebie pasują (安くて、おいしい; 広くて、きれい). Cechy przeciwne łączysz przez が lub でも: 安いですが、まずいです。

✗ 静かくて (な bierze で) · ✗ 安いで (い bierze くて) · ✗ いくて (いい → よくて) · ✗ 寒くで (くて, nie くで).
